# Changelog

All notable user-facing changes are recorded here.

## [Unreleased]

### Added

- Searchable model and thinking-level selectors with a ten-option visible window.
- Public documentation site and repository community files.

### Changed

- Non-TUI clients continue to use Pi's native selection dialog protocol.

## [0.1.0] - 2026-08-14

### Added

- Global and per-session subagent model commands.
- Optional thinking-level selection.
- Overrides for tool, slash-command, delegation, and RPC child launches.
- Global persistence and branch-aware session state.
